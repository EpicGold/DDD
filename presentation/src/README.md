# Как собрана презентация

Презентация: `../Авиация_Первой_мировой_войны.pptx` — 14 слайдов, 16:9, с переходами «Трансформация» (Morph) между всеми слайдами и заметками докладчика.

## Источники материалов
- **Фото экспонатов и рисунки** — Smithsonian Open Access (лицензия CC0): Национальный музей авиации и космонавтики США (самолёты, моторы, приборы), Национальный почтовый музей США (снаряжение лётчика, марка «Перевёрнутая Дженни»), Национальный музей американской истории (рисунки военных художников США 1918 г.). Файлы берутся из открытого бакета `smithsonian-open-access` по идентификаторам, перечисленным в `prep_assets.py`.
- **Карты** — рельеф и береговая линия Natural Earth (`naturalearth.s3.amazonaws.com`), границы 1914 года — репозиторий `aourednik/historical-basemaps`, линия Западного фронта 1915–1917 гг. — упрощённая, по опорным пунктам (см. `render_map.py`).

## Конвейер
1. `cutout.py` — удаление фона нейросетью BiRefNet (библиотека `rembg`).
2. `render_map.py` — отрисовка карт Европы и Западного фронта 1914 года.
3. `prep_assets.py`, `prep_extra.py` — обрезка и сжатие вырезок, градиенты, подсветка, чертёж «Ильи Муромца», координаты меток на картах.
4. `build.js` — сборка слайдов (`pptxgenjs`).
5. `morph.py` — добавление переходов «Трансформация» и удаление дубликатов картинок.

Переходы «Трансформация» работают в PowerPoint 2019, 2021 и Microsoft 365; в более старых версиях показывается «Угасание».

## Доклад (Word)
`../Доклад_Авиация_Первой_мировой_войны.docx` — доклад к презентации: титульный лист, содержание, введение, 12 разделов (с пометками «Слайд N»), заключение, список источников и приложение с планом выступления. Оформление: A4, Times New Roman 14, интервал 1,5, поля 3 / 1,5 / 2 / 2 см.

Сборка: `doklad/figs.py` (иллюстрации и подписанные карты) → `doklad/build_doc.js` (библиотека `docx`) → `doklad/pages.py` (номера страниц для содержания, затем повторная сборка).
